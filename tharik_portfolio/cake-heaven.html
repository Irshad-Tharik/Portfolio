01 / OVERVIEW

About the project.

Cake Heaven is an academic mobile application developed using Flutter and Dart. It allows users to explore cakes, view product details, manage a shopping cart, and proceed through the ordering process. Firebase Authentication supports user account management, while Firebase Realtime Database stores profile-related information.

02 / FEATURES

What it can do.

01

User authentication

Registration, login, logout and password reset using Firebase Authentication.

02

Cake catalogue

Browse categories, search products, and view descriptions, prices and ratings.

03

Shopping cart

Review selected cakes and manage item quantities before checkout.

04

Personalized experience

Manage profile information and use light or dark theme options.
